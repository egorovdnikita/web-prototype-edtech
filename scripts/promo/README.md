# Промо-ролик для README

Зацикленный WebP `docs/assets/edtech-demo.webp`: запись настоящего прототипа в мобильном размере 390 × 844 pt, кадр телефона по центру холста 1600 × 880, 30 кадров/с. Фон GitHub Dark `#0d1117`, обводка `#3d444d`, скругление 20 pt. Курсора нет, касания показаны кольцами в центрах настоящих кнопок, камера приближает место действия. Подход и кривые — как у промо Agent Pulse.

Сценарий: неделя обществознания → отметка конспекта в уроке 15 → «Практика» → тренажёр, №4 с ошибкой → ключ и пояснение → переключение на историю → «Интерактивные тренировки» → «Северная война на карте», четыре сражения нажатиями → «Без единой ошибки!» → возврат к неделе обществознания. Профиль браузера свежий: данные — моки прототипа, вымышленные.

## Как воспроизвести

Окружение и временные файлы — вне репозитория.

```sh
python3 -m venv /tmp/edtech-promo-env
/tmp/edtech-promo-env/bin/pip install pillow playwright
/tmp/edtech-promo-env/bin/python -m playwright install chromium

cd prototype && npm run build && npx next start -p 3123   # в отдельном терминале
cd ..
/tmp/edtech-promo-env/bin/python scripts/promo/record.py /tmp/edtech-promo
/tmp/edtech-promo-env/bin/python scripts/promo/compose.py /tmp/edtech-promo --keys 0.5   # контрольные PNG
/tmp/edtech-promo-env/bin/python scripts/promo/compose.py /tmp/edtech-promo --out docs/assets/edtech-demo.webp
```

- `record.py` — Playwright проходит сценарий в реальном времени, кадры экрана в PNG снимает CDP screencast. Пишет `frames/`, `frames.json` и `events.json`: касания с прямоугольниками кнопок и команды камеры.
- `compose.py` — монтаж: телефон, камера, кольца, стык петли. `--keys 0.5` сохраняет контрольные кадры каждые 0,5 с и последний кадр без кодирования.
- Петля: в конце ученица возвращается на неделю обществознания, последние 0,5 с сводятся к первому кадру — первый и последний кадры совпадают.
- Кодирует libwebp через Pillow, без потерь, кадры подаются по одному. Через ffmpeg анимация без потерь сдвигала цвета, а дельта-кадры с потерями оставляют бледные следы прежнего текста на белом. 30 кадров/с держат файл в пределах 20 МБ; `--fps 60` почти вдвое крупнее, `--lossy --quality 85` оставлен для сравнения.
- Кадры записи — PNG: шум JPEG увеличивал WebP без потерь примерно на 40%.
