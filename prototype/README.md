# Прототип кабинета ученика

Кликабельный прототип «покликать» кабинета ученика онлайн-школы подготовки к ЕГЭ. Без бекенда: данные — моки в `mocks/`, отметки сохраняются в localStorage браузера (сброс — «Ещё» → «Сбросить отметки прототипа»). Школа, люди, цены и тексты вымышленные.

Опубликован: https://edtech-lms-prototype.vercel.app (закрыт от поисковиков). Сценарий показа — `docs/demo.md`. Обновить публикацию: `npx vercel deploy --prod` из копии `prototype/` без `.git`, `node_modules` и `.next` (с папкой `.vercel`). Из самого репозитория Vercel блокирует деплой: считает, что у автора коммита нет прав на проект.

```
npm install
npm run dev
```

Открыть http://localhost:3000 — перекинет на `/soc`. Адаптив: телефон ниже 1024 px (вкладки снизу), десктоп — меню слева, на ширине от 1280 px — правая колонка.

## Как устроено

Ученица на двух предметах, «сегодня» — воскресенье 25.10.2026, неделя 8. Тарифы в моках разные, чтобы показать обе проверки ДЗ:

- обществознание — «Стандарт»: ДЗ уходит куратору, до проверки баллов нет. Пример проверенной работы — `/soc/work/soc-13-c/result`, с критериями и комментарием;
- история — «Базовый»: после сдачи открываются ключ и критерии, ученик ставит баллы сам, и экран прямо говорит, что это самопроверка.

Тарифы: «Лайт» (самопроверка, без наставника и розыгрыша), «Базовый» (самопроверка ДЗ, есть наставник), «Стандарт» (ДЗ проверяет куратор, есть зачёты), «Премиум» (то же, проверяет эксперт).

**Неделя.** Планер «Задачи на неделю»: «продолжить с» — один следующий шаг, долг с прошлой недели, фильтр «всё / обязательное / на 100». Допы «на 100» не входят в прогресс. Отметки ставятся сами по фактам (просмотр, сдача), руками — только офлайн-пункты.

**Работы.** Тесты на автопроверке: результат сразу, у ошибок — правильный ответ и пояснение, попытки сохраняются. Вопросы, ключи и критерии — `mocks/works.ts`.

**Календарь** общий для обоих предметов: уроки, дедлайны, вебинары, продлёнки, воркшопы и коворкинги (по записи, с лимитом мест) и зачёт из свободных окон наставника. Продлёнку ведёт проверяющий — в интерфейсе только его ник. Встречи — `mocks/meetings.ts`.

**Оплата.** Единый день оплаты 1-го числа, цена зафиксирована на год, два предмета одним платежом −10%, до конца курса −10% (скидки применяются по очереди). При просрочке открытое доступно до конца месяца, новое — после оплаты; не оплатил до конца месяца — отчисление: кабинет закрыт, кроме оплаты и «Ещё». Внизу страницы — демо-переключатель «сейчас / просрочка / отчисление»; деньги не списываются. Цены — `mocks/payment.ts`.

**До распределения к наставнику.** «Ещё» → «Демо-состояния», отдельно для предмета. Уроки, тесты и тренировки открыты; ДЗ и зачёт закрыты с объяснением, что делать сейчас и что дедлайн не сгорит. На странице наставника — ход подбора и кнопка «Демо: назначить наставника».

**Материалы курса** — вкладка «Программы». Вместо дерева папок — один экран: поиск, разделы фильтром, группы по темам; закрытые группы видны со сроком открытия. Сверху — «сейчас по программе». Сессии — итоговый тест, пробник и билеты к зачёту; на «Базовом» билетов нет, экран говорит почему. Файлы в прототипе не открываются: нажатие отмечает «просмотрено». `mocks/materials.ts`.

**Интерактивные тренировки.** 13 форматов сведены к 7 механикам на нажатиях, одинаковым на телефоне и десктопе: «выбери», «соедини пары», «пропуски», «порядок», «по категориям», «фрагменты в тексте» и «карта». Правило одно: нажми карточку → нажми место; ошибка — встряска и красная рамка, ничего не блокирует; после решения — пояснение. На телефоне варианты прилипают к низу экрана. Каталог форматов — `FORMATS` в `mocks/trainings.ts`, в прототипе 11 тренировок.

**Работа над ошибками** собирается сама из последней попытки каждого теста, тренажёра и тренировок. Верный ответ убирает задание из списка. В тренировках единица ошибки — элемент (пара, карточка, пропуск, точка на карте), перерешиваются только они; «порядок» и «найди ошибку» — целиком.

**Тренажёр по номерам ЕГЭ** (только обществознание): сетка номеров 1 части с процентом решаемости, подборки по номеру, «слабые» (ниже 60%) и микс. Проверка сразу; неверный ответ уходит в работу над ошибками. Банк — для №1–6, номера условные. `mocks/trainer.ts`.

**Мотивация.** Зачётка: обязательное задание = 10 баллов, печать за месяц при наборе больше 60%, печать = билет в розыгрыш, на «Лайте» розыгрыша нет. Печати — звезда (общество) и ромб (история). Ачивки выдаются сами и всплывают поверх экрана. `mocks/gradebook.ts`.

**Наставник и чаты.** У каждого предмета своя пара наставник + проверяющий. Переписка с голосовыми, индивидуальный план — пункты курса со сроком от наставника. Зачёт по видеосвязи — только на «Стандарте»: проверка камеры → билет → подготовка → ответ → результат (видео — заглушки). Чаты: мини-группа с наставником и общий чат курса; переносить ли чаты из мессенджера в платформу — открытый вопрос, на экране это помечено.

**Уведомления и профиль.** Уведомления общие на аккаунт, прочитанными становятся сами. Профиль сохраняется сам: часовой пояс с пересчётом, курсы, отчёт родителю, каналы по типам (Telegram, ВК, почта), рассылки школы по умолчанию выключены.

**Остальное.** Запись встречи (чат идёт вместе с записью), анкета после пробника, перепроверка бланков ЕГЭ, техподдержка, демонеделя и первый вход после покупки.

## Дизайн-система

Основа — [Box UI](https://github.com/egorovdnikita/box-ui): граф токенов Primitives → Brand → System, примитивы `Button / Badge / Card / Text / Stack`, иконки Solar. Box UI не опубликован в npm, поэтому в `src/vendor/box-ui/` лежит снимок:

```
npm run sync:box-ui                         # из ../../box-ui
BOX_UI_DIR=/path/to/box-ui npm run sync:box-ui
```

Иконки — только те, что перечислены в `scripts/icons.json` (два стиля: linear и bold). Нужна новая — добавить имя и перезапустить sync.

Стиль — моды Box UI в одном месте, `src/lib/style.ts`: Brand · Color `monochrome`, Brand · Typography `inter` (Inter грузит `next/font`), Brand · Icon `bold` (стрелки всегда контурные), радиусы `medium` (на телефоне Box UI сам берёт ступень меньше), светлая тема. Слой плоский: белая страница, карточки отделяют тонкие обводки, теней нет. Предмету можно дать свою моду Brand · Color одной строкой в `style.ts`.

Цвета — только роли Box UI. Текст: content strong / muted / subtle. Иконки по умолчанию — `content-subtle`; в кнопках, выбранном и на акцентной заливке иконка берёт цвет контрола, у кнопок из одной иконки — цвет текста. Подсветка — слой `layer-subtle`. Выбор — рамка акцента на белом. Состояния — System · Status через `data-status` на самом элементе (`bg-status-soft`, `text-status-ink`, `border-status-border`):
- `positive` — «верно», сделано, оплачено;
- `warning` — долг, просрочка, неоплаченный месяц;
- `negative` — ошибка в ответе, отчисление.

Иконки — только там, где они несут навигацию, состояние или действие; декоративных плиток нет. То, чего в Box UI нет, — в `src/styles/app.css`, всегда через его токены.

Контраст (`node ../scripts/contrast.mjs --palette`): белый на чёрной кнопке — 21, основной текст на белом — 17.93; статусный текст: positive 8.05, warning 7.09, negative 10.02. Иконки `content-subtle` (#A3A3A3) — 2.52: только рядом с подписью. Вторичный текст Box UI (#737373) на сером слое даёт 4.35 — ниже AA, поэтому в прототипе он заменён на neutral-600 (#525252): 7.81 на белом, 7.17 на сером. Это стоит исправить в самой Box UI.

В компонентах нет hex: Tailwind-цвета `surface-*`, `accent-*`, `ink-*`, `line-*`, `status-*` и радиусы `rounded-box-*` смотрят в токены (`tailwind.config.ts`). Радиусы названы `box-*`, потому что `rounded-s` и `rounded-l` в Tailwind заняты логическими сторонами.
