# Прототип

Каркас уже создан: Next.js 14 (App Router, `src/`), TypeScript, Tailwind v3, shadcn/ui (new-york, CSS-переменные). Моки данных — в `mocks/`.

```
npm install
npm run dev
```

Компоненты shadcn добавляются так: `npx shadcn@2.3.0 add button`.

Следующий шаг — попроси Claude Code собрать токены (`surface` / `accent` / `ink` для обществознания и истории) и первый экран — планер недели.
