# Показ прототипа кабинета ученика

Ссылка: https://enl-prototype.vercel.app — закрыта от поисковиков, данные — моки, деньги не списываются.
Отметки сохраняются в браузере зрителя. Перед показом: «Ещё» → «Сбросить отметки прототипа».

«Сегодня» в прототипе — воскресенье 25.10.2026, неделя 8. Ученица учит два предмета:

- обществознание на тарифе «С инструктором» — ДЗ проверяет куратор, есть зачёт;
- историю на тарифе «Фристайл» — самопроверка, зачётов нет.

## Сценарий на 12–15 минут

Показывать с телефона или в узком окне: мобильная версия — главный аргумент против вайрфреймов, которые только десктопные.

1. **Неделя** (`/soc`). Это планер-чек-лист, любимый элемент учеников. Обратить внимание:
   - «продолжить с»;
   - долг с прошлой недели с плашкой «прямо сейчас!»;
   - фильтр «обязательное / на 100».

   Допы не выглядят как долг и не входят в прогресс.
2. **Переключить на историю.** Тот же интерфейс в другом цвете: предмет — тема токенов, новый предмет = один цвет. Вернуться в обществознание.
3. **Урок 15** → отметить конспект → решить «Тест по уроку» с одной ошибкой. Результат приходит сразу, у ошибки есть пояснение.
4. **Практика → Тренажёр.** Сетка номеров с процентом решаемости — её уже наполнили тесты уроков. Нажать №4, ошибиться — ключ и пояснение сразу, задание уходит в работу над ошибками.
   **Практика → Работа над ошибками.** Ошибка из теста уже здесь. Перерешать верно — ошибка уходит из списка, приходит ачивка «разобрался». Ошибки тренировок тоже попадают сюда и перерешиваются в той же механике — только там, где ошиблись.
5. **Тренировка с телефона** — «Практика» → «Интерактивные тренировки», например «Северная война на карте» или «Найди ошибки: власть в РФ». Сейчас 8 из 13 форматов ЕНЛ держатся на перетаскивании или наведении и на телефоне не работают. Здесь всё нажатием: карточка → место, ошибка не блокирует, в конце — пояснение.
6. **ДЗ.** Разница тарифов:
   - обществознание: ДЗ «на проверке», баллов до проверки нет (сейчас GetCourse ставит максимум заранее). Проверенный пример — `/soc/work/soc-13-c/result`;
   - история: после сдачи ученик оценивает себя по критериям, экран прямо называет это самопроверкой.
7. **Прогресс → Зачётка.** Октябрь растёт от сделанного в шагах 3–6. Печать за месяц, если обязательный план выполнен больше чем на 60%. Звезда и птица — как на текущей платформе.
8. **Календарь.** Записаться на коворкинг (лимит мест) и на зачёт из свободных окон наставника. Запись появляется во «Встречах недели» на главной. Продлёнку ведёт проверяющий — в интерфейсе только его ник.
9. **Наставник → Зачёт.** Переписка, индивидуальный план пунктами курса. Зачёт по видеосвязи: проверка камеры → билет → подготовка → ответ → «зачтено».
10. **Оплата.** Сначала обычное состояние: оба предмета одним платежом −10%, итог 7 245 ₽. Потом демо-переключатель внизу страницы:
   - «просрочка» — баннер на всех экранах; вернуться можно остатком ноября или декабрём, ноябрь тогда останется закрытым;
   - «отчисление» — кабинет закрыт, кроме оплаты.

## Чего в прототипе нет

- Техподдержка — заглушка в «Ещё».
- Тренажёр по номерам ЕГЭ — только сетка номеров.
- Видео — заглушки, камеру зачёт не запрашивает.
- Роли учебной команды, методиста, родителя.
