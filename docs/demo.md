# Показ прототипа кабинета ученика

Ссылка: https://edtech-lms-prototype.vercel.app — закрыта от поисковиков, школа и данные вымышленные, деньги не списываются.

## Зачем показ

Получить три решения:

1. **Визуальная основа** — прототип в нейтральном стиле дизайн-системы Box UI: монохром, Inter, залитые иконки (стрелки контурные), белая страница без теней. Цвет — только у состояний. Это каркас, а не бренд: бренд школы ложится модами дизайн-системы без переделки экранов.
2. **Логика кабинета** — неделя-планер как главная, пять разделов меню, один экран материалов вместо дерева папок.
3. **Что дальше** — кабинет ученика готов; следующим — кабинет методиста (конструктор курса и урока).

## Перед показом (5 минут)

- Открыть ссылку в узком окне или с телефона: мобильная версия — главный аргумент.
- «Ещё» → «Сбросить отметки прототипа». Отметки хранятся в браузере зрителя, после сброса всё как в моках.
- Проверить, что в «Ещё» → «Демо-состояния» ничего не включено, а на странице оплаты стоит «сейчас».
- «Сегодня» в прототипе — воскресенье 25.10.2026, неделя 8. Ученица учит два предмета:
  - обществознание, тариф «Стандарт» — ДЗ проверяет куратор, есть зачёт;
  - история, тариф «Базовый» — самопроверка ДЗ, зачётов нет.

## Основной показ — 15 минут

### 1. Неделя ученика (5 минут)

1. **Неделя** (`/soc`) — планер «Задачи на неделю». Показать:
   - «продолжить с» — один следующий шаг, без инструкции;
   - долг с прошлой недели — янтарным статусом, «можно сдать до 06.11»;
   - фильтр «обязательное / на 100»: допы не выглядят как долг и не входят в прогресс.
2. **Переключить на историю** в шапке. Интерфейс тот же, меняется содержание. Предмету можно дать свой цвет одной модой дизайн-системы. Вернуться в обществознание.
3. **Урок 15** из планера → отметить конспект → «Тест по уроку», ошибиться в одном вопросе. Результат сразу, у ошибки — пояснение.
4. **Практика → Работа над ошибками.** Ошибка из теста уже здесь. Перерешать верно — уходит из списка, всплывает ачивка.

### 2. Что упрощено (5 минут)

5. **Программа → Материалы курса.** Один экран вместо дерева папок: поиск («демоверсия»), разделы, «сейчас по программе». На истории в «Сессиях» нет билетов к зачёту — тариф «Базовый», экран объясняет почему.
6. **Тренировка с телефона.** «Практика» → «Интерактивные тренировки» → «Северная война на карте». Перетаскивание и наведение на телефоне не работают — здесь всё нажатием: сражение → точка на карте, ошибка не блокирует, в конце пояснение.
7. **Практика → Тренажёр по номерам.** Сетку номеров уже наполнили тесты уроков. Нажать №4, ошибиться — ключ и пояснение сразу, задание уходит в работу над ошибками.
8. **Колокольчик** в шапке. Уведомления обоих предметов одним списком, прочитанными становятся сами. Дальше «Куда присылать» → профиль: каналы по типам, рассылки школы выключены по умолчанию.

### 3. Мотивация и люди (5 минут)

9. **Прогресс → Зачётка.** Октябрь вырос от сделанного в шагах 3–4. Печать за месяц, если обязательный план выполнен больше чем на 60%.
10. **Прогресс → Ачивки.** Медали с венком и лентой, новые всплывают сами.
11. **Ещё → Наставник.** Переписка, индивидуальный план пунктами курса, зачёты. Войти в зачёт по видеосвязи: проверка камеры → билет → подготовка → ответ → «зачтено».
12. **Ещё → Чаты.** Мини-группа с наставником и чат курса с дежурным. Перенос чатов из мессенджера в платформу — открытый вопрос, это показ «как могло бы быть».

## На что смотреть в визуале

- **Стиль — моды дизайн-системы.** Box UI: монохром, Inter, залитые иконки Bold (стрелки контурные, цвет иконок — третичный), белая страница без теней — карточки отделяют тонкие обводки. Иконки только там, где они что-то значат.
- **Цвет — только у состояний**, по правилам Box UI: зелёный — верно и сделано, янтарный — долг и просрочка, красный — ошибка.
- **Контраст по WCAG.** Основной текст 17.93, кнопки 21, статусный текст 7.09–10.02. Вторичный текст Box UI по умолчанию даёт 4.35 — ниже нормы, в прототипе поднят до 7.81.
- **Скругления.** Средние, на телефоне дизайн-система сама берёт ступень меньше. Переключается одним режимом, без переделки экранов.
- **Иллюстраций нет.** Обложки уроков и ачивки — отдельная работа с иллюстратором.

## Открытые вопросы

| Вопрос | Как в прототипе |
|---|---|
| Визуальная основа: нейтральный Box UI или бренд школы модами? | Нейтральный Box UI |
| Чаты: в платформе или в мессенджере? | Внутри, с пометкой |
| Рассылки школы в профиле по умолчанию выключены — только с согласия? | Выключены |
| «Месяц обучения»: с 1-го числа или по неделям? | С 1-го числа |
| Как складываются скидки «два предмета» и «до конца курса»? | По очереди |
| Мобильное поведение тренировок: 7 механик на нажатиях для всех устройств? | Так |
| Ошибки из тренировок: перерешивать только элементы с ошибками, порядок и «найди ошибку» — целиком? | Так |
| До распределения: ДЗ закрыто или черновиком? | Закрыто, срок не обещаем |

## Чего в прототипе нет — сказать заранее

- Только ученик. Кабинетов наставника, проверяющего, методиста, магазина и отчёта родителю нет.
- Вход и пароль не сделаны.
- Видео, файлы и камера — заглушки. Данные живут в браузере зрителя.
- Время везде московское, часовой пояс пересчитывается только в профиле.
- Демонеделя открывается внутри обычного кабинета — урезанной навигации для гостя нет.
- Иллюстраций и обложек уроков нет.
