# Web Prototype EdTech

Кликабельный прототип LMS — кабинета ученика онлайн-школы подготовки к ЕГЭ по обществознанию и истории, на дизайн-системе Box UI, для телефона и десктопа.

**→ [Открыть демо](https://edtech-lms-prototype.vercel.app)**

## Что умеет

- **Неделя-планер.** «Задачи на неделю»: один следующий шаг «продолжить с», долг с прошлой недели, фильтр «всё / обязательное / на 100».
- **Работы и проверка.** Тесты на автопроверке с пояснениями к ошибкам; ДЗ проверяет куратор или сам ученик по ключу — зависит от тарифа.
- **Практика.** Работа над ошибками собирается сама; тренажёр по номерам ЕГЭ с решаемостью; 11 интерактивных тренировок — 7 механик на нажатиях вместо перетаскивания.
- **Материалы курса.** Один экран вместо дерева папок: поиск, разделы, группы по темам, «сейчас по программе».
- **Календарь и наставник.** Общий календарь обоих предметов с записью на встречи, переписка с наставником, индивидуальный план, зачёт по видеосвязи.
- **Мотивация.** Зачётка с баллами и печатями месяца, розыгрыш, ачивки.
- **Оплата.** Оплаченный период, скидки, просрочка и отчисление — с демо-переключателем, деньги не списываются.
- **Аккаунт.** Уведомления обоих предметов одним списком, профиль с каналами уведомлений, техподдержка, перепроверка бланков ЕГЭ.

## Запуск

Нужен Node 18.17+.

```bash
cd prototype
npm install
npm run dev
```

Открой `http://localhost:3000` — перекинет на недельный планер `/soc`. Отметки хранятся в localStorage браузера, сброс — «Ещё» → «Сбросить отметки прототипа». Тестов нет, проверка — `npm run build` и `npm run lint`.

## Устройство

| Путь                           | Что там                                                        |
| ------------------------------ | -------------------------------------------------------------- |
| `prototype/src/app/[subject]/` | экраны, предмет в адресе: `/soc` или `/hist`                   |
| `prototype/mocks/`             | моки вместо бекенда: курс, работы, встречи, оплата, тренировки |
| `prototype/src/vendor/box-ui/` | снимок Box UI, обновляется `npm run sync:box-ui`               |
| `prototype/src/lib/style.ts`   | моды Box UI: цвет, типографика, иконки, радиусы                |
| `scripts/contrast.mjs`         | расчёт контраста WCAG: `node scripts/contrast.mjs --palette`   |
