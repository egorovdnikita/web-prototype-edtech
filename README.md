# ЕГЭ налегке — дизайн LMS

Рабочий репозиторий дизайна LMS для онлайн-школы «ЕГЭ налегке»: контекст проекта, референсы и кликабельный прототип.

- `CLAUDE.md` — правила работы для Claude Code
- `docs/` — контекст проекта и разбор материалов FANS
- `refs/wireframes-2026-10-22/` — вайрфреймы FANS от 22.10 (открыть `wireframes.html`)
- `prototype/` — Next.js-прототип (`cd prototype && npm install && npm run dev`)
- `scripts/contrast.mjs` — расчёт контраста WCAG: `node scripts/contrast.mjs --palette`

Персональные данные учеников и сотрудников в репозиторий не кладём.
