# Прототип LMS для онлайн-школы

Кликабельный прототип кабинета ученика онлайн-школы подготовки к ЕГЭ на дизайн-системе Box UI. Школа, люди, цены и тексты вымышленные.

- `CLAUDE.md` — правила работы для Claude Code
- `docs/demo.md` — сценарий показа прототипа
- `prototype/` — Next.js-прототип (`cd prototype && npm install && npm run dev`)
- `scripts/contrast.mjs` — расчёт контраста WCAG: `node scripts/contrast.mjs --palette`

Персональные данные и реальные материалы в репозиторий не кладём.
