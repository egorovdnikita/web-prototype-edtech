# Прототип LMS для онлайн-школы

Кликабельный прототип кабинета ученика онлайн-школы подготовки к ЕГЭ (два предмета: обществознание и история). Я — Никита Егоров, продуктовый дизайнер: концепция, UX, UI и дизайн-система. Школа, люди, цены и тексты в прототипе вымышленные; названия и материалы реальных компаний не используем.

Сценарий показа — `docs/demo.md`. Подробности о прототипе — `prototype/README.md`.

## Как работать

- Отвечай по-русски, коротко и по делу. Критикуй прямо, давай одну рекомендацию, а не список вариантов.
- Любое дизайн-решение проверяй по трём фильтрам:
  1. ученик-подросток понимает следующий шаг без инструкции;
  2. решение работает на телефоне;
  3. оно масштабируется на новые предметы, тарифы и смену визуальных концепций без переделки.
- Для цвета всегда считай контраст по WCAG: `node scripts/contrast.mjs <цвет1> <цвет2>`. Не считай на глаз.
- Декоративность — язык маркетинга, а не интерфейса. Если в UI её становится больше, чем нужно для смысла, говори об этом.
- Если факт не подтверждён, так и говори, не додумывай.

## Прототип

- Папка `prototype/`. Next.js 14 App Router, TypeScript, Tailwind v3.
- Дизайн-система — Box UI (github.com/egorovdnikita/box-ui): токены, примитивы и иконки лежат снимком в `prototype/src/vendor/box-ui/`, обновляются `npm run sync:box-ui`. Руками vendor не правим.
- Стиль прототипа — моды Box UI в одном месте, `prototype/src/lib/style.ts`: Brand · Color `monochrome`, Brand · Typography `inter`, Brand · Icon `bold` (стрелки контурные), радиусы `medium`, светлая тема Box UI. Теней нет: слои делят обводки на белой странице.
- Цвета — только роли Box UI: content strong / muted / subtle, layer-subtle, accent, System · Status через `data-status` (positive — верно, warning — долг и просрочка, negative — ошибка). Иконки — `content-subtle`, без декоративных плиток; иконка — только там, где она несёт навигацию, состояние или действие.
- То, чего в Box UI нет, — в `prototype/src/styles/app.css`, всегда через его токены. Новый предмет может получить свою моду Brand · Color одной строкой в `style.ts`.
- Сначала компонент Box UI, своё — только если в Box UI нет аналога.
- Это прототип «покликать», а не прод: без бекенда, данные — моки в `prototype/mocks/`.
- Цвета только через токены (Tailwind `surface-*` / `accent-*` / `ink-*` / `line-*` / `status-*`, радиусы `rounded-box-*`), никаких hex в компонентах.
- Mobile-first: каждый экран проверяй на ширине 375px и на десктопе 1280+.

## Безопасность

- Никаких персональных данных в репозитории: только вымышленные люди и контакты на `example.com`.
- Никаких паролей, секретов и реальных материалов заказчиков в файлах.
